# Alert Inbox and Foundation Acceptance Closeout

Date: 2026-11-26. **Subphase 5F.5 Complete.**

## Delivered Scope

The local `/alerts` module has immutable typed selector definitions, atomic
evidence-linked alerts, deterministic deduplication, explicit bounded local
catch-up, review filtering and revision-checked review history. Existing
shared observation writes and report saves create matches in their evidence
transaction. A match failure rolls back that write. No new dependency,
collection adapter, scheduler, network worker or arbitrary rule engine.

Exact domain, IP, hash, URL, email and CVE values use shared normalization.
Domain trees respect label boundaries. Strict CIDR networks match typed IP
observations. Definitions are capped at 100, including disabled entries;
values at 2,048 characters. Each catch-up page checks at most 200 observations
for one selector, with alerts and a durable cursor committed together.
Definitions cannot be rewritten or silently re-enabled by replay. Generic
unsupported subjects remain evidence without a guessed match.

Uniqueness is selector plus immutable observation. Separate sources,
assertions and captures remain separate even for equal subjects. Replay
never duplicates the alert or resets New/Reviewed/Dismissed state. Review
changes append dated revisions; stale forms return 409. This is review
workflow, not source credibility or an independent-corroboration assessment.

Details retain the source assertion, separate published/modified/observed/
first-seen/last-seen/collected dates, capture identity, literal unresolved or
explicitly resolved citation hops and originating execution. An interrupted
originating run and a later successful logical job are displayed separately.
Legacy opaque run IDs stay passive metadata. Archive omission, expiry and
reconciliation failure preserve indicator, citation, alert and review history.

The inbox reuses the existing read-only freshness panel. Details show capture
age plus relevant registered source freshness, or explicitly state that no
scheduled assessment exists. Originals are never rendered/served. Non-public
or restricted-TLP excerpts are suppressed. Source references remain escaped
passive text. GETs do not scan history, reconcile originals, dispatch work or
poll providers. Selectors never grant collection permission or select work,
callables, commands, destinations, credentials or approval.
