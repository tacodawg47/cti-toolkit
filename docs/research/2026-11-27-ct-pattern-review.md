# CT Watch Keyword and Pattern Review

Date: 2026-11-27. Version: 2026-11-27.1. Public primary reporting only.
The versioned list is app/modules/ct_watch/patterns-v1.json. No source dataset,
service code, screenshots or copied report prose is shipped.

Read the complete public article text of Okta's
[2026-07-10 recovery advisory](https://www.okta.com/blog/threat-intelligence/intrusion-actors-self-serve-their-way-into-accounts/).
It reports passkey strings in phishing domains and describes support
impersonation and enrollment/recovery pretexts. Passkey is a reported domain
token. The other recovery/support terms in the list are explicitly local
hypotheses derived from that behavior, not reported domain indicators.

Read the complete public article text of Okta's
[2026-11-23 INCEPTION advisory](https://www.okta.com/blog/threat-intelligence/former_shinyhunters_cluster_moves_to_new_inception_site/).
Its public domain examples support literal legal and legaldept theme tokens.
The code checks complete labels and hyphen-separated tokens. It does not
generate the article's example patterns or query target infrastructure.

IAM/MFA brand names and the remaining auth nouns come from the existing
roadmap. Their basis is labelled separately. Neither report establishes
that every roadmap token was used in an observed campaign. Theme matches
only annotate an exact authorized seed match. A theme alone creates no hit.

Only operator-approved DNS tokens represent organizations and brands. There
is no automatic abbreviation, alias, transliteration, homoglyph, permutation,
substring or registrable-domain inference. IDNA2008 canonical spelling uses
the existing pinned idna package. Wildcards retain their literal pattern
scope and never establish an apex or an enumerated host.

Unchecked material: authenticated Okta Trust Center indicators, gated
figures/appendices, outgoing reference links and images were not collected.
Microsoft's 2026-09-09 passkey article was inspected in part but not used as
a load-bearing source for this version. Search results and third-party
summaries were discovery aids, not evidence. This is a curated starting
vocabulary, not a comprehensive inventory or an attribution/signature list.
